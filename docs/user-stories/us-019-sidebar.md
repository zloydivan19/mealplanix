# US-019 — Боковая панель навигации (Sidebar)

**Эпик:** Инфраструктура и фундамент  
**Приоритет:** 🟡 средний  
**Статус:** ✔️ готово  
**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу иметь удобную навигацию по разделам приложения,
чтобы быстро переходить между планировщиком и настройками.

## Сценарий

1. В шапке приложения слева вижу кнопку-бургер (три горизонтальные линии)
2. Нажимаю бургер → слева выезжает панель навигации с анимацией (250ms)
3. Позади панели появляется затемнённый оверлей
4. В панели вижу логотип, кнопку закрытия и список разделов
5. Нажимаю на раздел → перехожу на страницу, панель закрывается
6. Нажимаю на оверлей → панель закрывается
7. Текущий активный раздел подсвечен зелёным

## Разделы навигации

| Иконка | Название | Путь |
|--------|----------|------|
| Календарь | Планировщик | `/` |
| Шестерёнка | Настройки | `/settings` |

## UI-детали

- Ширина панели: 240px
- Анимация: `transform: translateX(-100% → 0)`, 250ms cubic-bezier
- Оверлей: `rgba(0,0,0,0.35)`, клик закрывает
- Активный пункт: bg `#E8F5E9`, цвет `green-primary`
- Hover неактивного: bg `var(--color-bg-page)`
- Шапка панели: логотип 36px + кнопка ✕
