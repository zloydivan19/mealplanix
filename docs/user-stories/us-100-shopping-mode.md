# US-100: Мобильный режим покупок

**Статус:** ✔️ готово
**Эпик:** Phase 3 — Premium Value
**Дата:** 2026-05-12

---

## User Story

> Как пользователь в магазине, я хочу нажать кнопку **«Режим покупок»** на `/cart` и получить упрощённый полноэкранный интерфейс — крупные карточки товаров, большие чекбоксы, прогресс «X из Y», сумма потраченного. Чтобы быстро проходить список одной рукой, не отвлекаясь.

---

## Acceptance Criteria

1. На `/cart` есть кнопка **«Режим покупок»** в шапке (видна на мобильных и десктопе).
2. По клику открывается полноэкранный режим:
   - Скрыт глобальный сайдбар и хедер сайта
   - Только товары, шапка-прогресс и кнопка «Завершить»
3. Товары сгруппированы по shopping-категориям (мясо / молочные / овощи / …).
4. Карточка товара:
   - Название (крупно, 18px)
   - Граммы / штуки
   - Цена за позицию
   - Большой чекбокс (минимум 32×32px)
   - При тапе по карточке — чекбокс переключается
5. Шапка-прогресс (sticky сверху):
   - «N из M товаров»
   - «X ₽ из Y ₽» (текущая сумма из суммы потраченного / итого)
   - Прогресс-бар
6. Wake Lock API — экран не гаснет пока режим активен.
7. Кнопка «Завершить» → подтверждение → купленные позиции переносятся в холодильник, режим закрывается.
8. **После закрытия** на `/cart` показывается баннер:
   > «Последняя закупка: 12 мая · 28 позиций · 3 200 ₽»
9. Баннер виден до следующей закупки или до начала новой недели.

## Технические детали

### Схема БД

Расширение существующей таблицы `cart_state`:

```sql
ALTER TABLE public.cart_state
  ADD COLUMN IF NOT EXISTS last_shopped_at        timestamptz,
  ADD COLUMN IF NOT EXISTS last_shopped_total_rub numeric,
  ADD COLUMN IF NOT EXISTS last_shopped_items     integer;
```

### Архитектура UI

- Новый компонент `ShoppingModeView.svelte` — full-screen overlay
- Используется `position: fixed; inset: 0; z-index: var(--z-modal-top)`
- Активируется через `$state` флаг в `+page.svelte` корзины
- Wake Lock через `navigator.wakeLock.request('screen')` с обработкой `release`

### Перенос в холодильник

Используется существующая логика из `V5-053`. После завершения режима покупок все товары с `bought=true` отправляются в `household_fridge`.
