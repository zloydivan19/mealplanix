# PlanMeal — Product Roadmap

---

# Phase 1 — Close the Loop

Goal:
Замкнуть цикл планирования.

Focus features:

- Add to fridge from cart
- Manual cart items
- Copy week
- Household invites
- Basic roles

Expected impact:

- рост retention
- рост weekly planning
- снижение ручного труда

Target metric:

Household Weekly Completion Rate

---

# Phase 2 — Product Differentiation

Goal:
Сделать продукт сильнее конкурентов.

Features:

- Saved weeks / templates
- Smart leftovers
- Fridge-aware generation
- Smart substitutes

Expected impact:

- уникальность продукта
- уменьшение food waste
- снижение времени планирования

---

# Phase 3 — Premium Value

Goal:
Подготовить монетизацию.

Features:

- Budget mode
- Premium household
- Shopping mode
- Nutrition analytics
- Recipe import

Expected impact:

- платные функции
- увеличение LTV

---

# Phase 4 — Growth

Goal:
органический рост продукта.

Features:

- Share week
- PDF export
- Weekly reminders
- Shopping analytics
- Household activity feed

Expected impact:

- вирусность
- увеличение MAU
