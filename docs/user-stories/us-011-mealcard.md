# US-011 — MealCard: добавление и отображение блюда в слоте

**Эпик:** Меню

**Статус:** ✅ утверждено  
**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу нажать на пустой слот в сетке и выбрать блюдо из списка,
чтобы заполнить меню на неделю и видеть КБЖУ каждого приёма пищи.

## Сценарии

### SC-1: Добавить блюдо
1. Нажимаю на пустой слот (например, Завтрак / Среда)
2. Открывается модалка со списком блюд + поиском по названию
3. Нажимаю на блюдо → оно появляется в слоте
4. Слот показывает: название, ккал · Б Ж У, стоимость

### SC-2: Удалить блюдо
1. На заполненном слоте нажимаю ✕
2. Слот снова становится пустым

### SC-3: Сохранение
- При добавлении блюдо сохраняется в `menu_plans` (Supabase)
- При загрузке страницы / смене недели планы загружаются из Supabase
- Удаление — физически удаляет запись из `menu_plans`
