# US-021 — Онбординг: выбор режима КБЖУ

**Эпик:** Настройки  
**Приоритет:** 🟡 средний  
**Статус:** ✔️ готово  
**Дата:** 2026-04-08

## Описание
Как новый пользователь, я хочу сразу выбрать — буду ли я следить за калориями,
или просто хочу удобное меню без подсчётов, чтобы не заполнять лишние поля
если КБЖУ меня не интересует.

## Проблема / Мотивация

Часть пользователей приходит не за подсчётом калорий, а за удобным планированием
еды на неделю. Обязательные поля (возраст, вес, рост, активность) создают барьер
при регистрации и могут отпугнуть эту аудиторию.

## Сценарий А — "Просто планирую меню" (по умолчанию)

1. На шаге 2 онбординга вижу тумблер "Считаю калории и слежу за КБЖУ" — **выключен**
2. Форма короткая: только имя и пол
3. Текст под тумблером: "Без подсчётов — просто удобное меню на неделю.
   Блюда будут подбираться случайно из доступных вариантов.
   Включить учёт КБЖУ можно в настройках в любой момент."
4. Нажимаю "Готово" → создаётся персона с `match_kcal=false`, без параметров тела

## Сценарий Б — "Считаю калории"

1. Включаю тумблер "Считаю калории и слежу за КБЖУ"
2. Разворачиваются поля: возраст, вес, рост, активность
3. После заполнения вижу блок "Твоя суточная норма" с расчётом КБЖУ
4. Могу скорректировать калории вручную
5. Задаю распределение по приёмам (Завтрак / Обед / Ужин, сумма = 100%)
6. Нажимаю "Готово" → создаётся персона с `match_kcal=true` и расчётными нормами

## UI-поведение тумблера

- Выключен (по умолчанию): блок с параметрами тела и КБЖУ скрыт
- Включён: блок разворачивается с полями
- Граница карточки меняет цвет: серая → зелёная (`green-primary`)
- Фон карточки: светло-серый → светло-зелёный (`#E8F5E9`)

## Данные в Supabase при сохранении

| Поле | "Просто планирую" | "Считаю калории" |
|------|-------------------|------------------|
| `match_kcal` | `false` | `true` |
| `age / weight / height` | `null` | значения |
| `activity` | `null` | выбранное |
| `kcal_target / protein_target / fat_target / carbs_target` | `null` | расчётные |
| `meal_ratios` | `{bf:25, ln:40, dn:35}` | введённые |
| `carry_dinner_to_lunch` | `true` | `true` |
