# US-018 — Автогенерация меню на неделю

**Эпик:** Меню  
**Приоритет:** 🔴 критично  
**Статус:** ✅ утверждено  
**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу нажать одну кнопку и получить заполненное меню на неделю,
чтобы не тратить время на ручной подбор блюд каждый день.

## Сценарий

1. На главном экране (WeekGrid) нажимаю кнопку **"Сгенерировать меню"**
2. Появляется подтверждение: "Заполнить меню на эту неделю? Текущие блюда будут заменены"
3. Нажимаю "Да" → все 21 слот недели заполняются автоматически
4. Меню сохраняется в Supabase — F5 не обнуляет

## Алгоритм генерации

### Входные данные
- `persona.kcal_target` — суточная норма калорий
- `persona.meal_ratios` — `{bf, ln, dn}` в процентах (например 25/40/35)
- `SEED_DISHES` — список блюд по категориям (bf / ln / dn)
- Настройка `carry_dinner_to_lunch` (bool) — из профиля пользователя

### Целевые ккал по приёму на день
```
target_bf = kcal_target × bf / 100
target_ln = kcal_target × ln / 100
target_dn = kcal_target × dn / 100
```

### Для каждого дня (Пн → Вс):

**Завтрак (bf):**
- Выбрать блюдо из категории `bf` с `kcal` ближайшим к `target_bf`
- Не повторять блюдо предыдущего дня (если есть альтернативы)

**Ужин (dn):**
- Выбрать блюдо из категории `dn` с `kcal` ближайшим к `target_dn`
- Не повторять блюдо предыдущего дня (если есть альтернативы)

**Обед (ln):**
- Если `carry_dinner_to_lunch = true` И день НЕ понедельник:
  → поставить то же блюдо, что было на **ужин предыдущего дня**
- Иначе (понедельник ИЛИ настройка выключена):
  → выбрать блюдо из категории `ln` с `kcal` ближайшим к `target_ln`
  → не повторять блюдо предыдущего дня (если есть альтернативы)

**Пример (carry ON, норма 2000 ккал, 25/40/35):**
```
Пн: Завтрак — Сырники (230 ккал)   | Обед — Котлеты с макаронами (190 ккал)  | Ужин — Биточки + салат (138 ккал)
Вт: Завтрак — Яичница (170 ккал)   | Обед — Биточки + салат (← ужин Пн)     | Ужин — Тушёная говядина (145 ккал)
Ср: Завтрак — Оладьи (220 ккал)    | Обед — Тушёная говядина (← ужин Вт)    | Ужин — Стейк индейки (135 ккал)
...
```

## Настройка "Ужин → обед следующего дня"

- Хранится в `personas.settings jsonb` (или отдельное поле `carry_dinner_to_lunch boolean`)
- По умолчанию: **включена**
- Расположение в UI: Настройки персоны → раздел "Генерация меню"
- Лейбл: "Переносить ужин на обед следующего дня"
- Подсказка: "Готовишь несколько порций сразу — одна идёт на ужин, другая на завтра в обед"
