# V5-097: Генерация меню с учётом холодильника — Дизайн

**Дата:** 2026-04-22  
**Статус:** Утверждён

---

## Цель

При генерации меню пользователь может указать продукты из холодильника, которые нужно «использовать» — генератор приоритизирует блюда, содержащие эти продукты, на столько приёмов пищи, сколько позволяет запас.

---

## UX-поток

1. Кнопка «Сгенерировать» превращается в **split-кнопку**: основная часть (обычная генерация) + стрелка-дропдаун.
2. Дропдаун содержит два пункта:
   - «🎲 Сгенерировать случайно» — текущее поведение (открывает существующий диалог подтверждения)
   - «🧊 С учётом холодильника…» — открывает `FridgeSelectModal`
3. **`FridgeSelectModal`** — диалог:
   - Список продуктов из `household_fridge` (только те, у кого `qty > 0`)
   - Чекбокс на каждый продукт; по умолчанию — все выбраны
   - Кнопки «Выбрать все» / «Снять все»
   - Счётчик «N выбрано»
   - Кнопка «⚡ Сгенерировать с N продуктами» — запускает генерацию
   - Закрытие: кнопка ✕ или Escape
4. Если холодильник пуст — пункт «С учётом холодильника…» отключён (серый, без клика).

---

## Логика матчинга продуктов → блюда

Для каждого выбранного продукта из холодильника ищем блюда в объединённом каталоге (`foodCatalog + customDishes`), у которых хотя бы один `ingredient.name` содержит `product_name` (case-insensitive, trim).

```
matched = catalog.filter(dish =>
  dish.ingredients.some(ing =>
    ing.name.toLowerCase().includes(product.product_name.toLowerCase().trim())
  )
)
```

Если `matched` пуст — продукт тихо игнорируется.

---

## Расчёт бюджета порций

Для каждого продукта с непустым `matched`:

1. Найти среди `matched` ингредиент с максимальным `qty` (граммовка на порцию из `DishIngredient.qty`).
2. Если `qty` не задан ни в одном блюде — использовать фолбэк 150г.
3. `budget = Math.floor(fridge.qty / portion_qty_g)` — сколько приёмов пищи можно покрыть этим продуктом.
4. Единица в холодильнике должна быть граммовой (`г`, `кг`×1000). Для `шт`, `л`, `мл` — использовать фолбэк 150.

Итог: список `FridgeHint[]`:
```ts
interface FridgeHint {
  dishIds:   number[];   // id блюд, содержащих этот продукт
  slotsLeft: number;     // сколько приёмов ещё можно покрыть
}
```

## Изменения в генераторе (`generate.ts`)

### `GenerateOptions` — новое поле

```ts
fridgeHints?: FridgeHint[];
```

### Препроцессинг

Новая функция `buildFridgeHints(products: SelectedFridgeProduct[], catalog: Dish[]): FridgeHint[]` — вызывается до `generateWeekPlan`, результат передаётся в opts.

### `pickDish` — приоритет hints

```ts
function pickDish(dishes, target, excludeIds, matchKcal, hints?): Dish
```

- Если есть активные hints (у кого `slotsLeft > 0`) и пересечение их `dishIds` с текущим `pool` непусто — берём из пересечения.
- После выбора уменьшаем `slotsLeft` у использованного hint на 1; если стало 0 — hint деактивируется.
- Если пересечения нет — обычный выбор из `pool`.

**Мутация hints** происходит in-place внутри `generateWeekPlan` (hints — объекты, переданные по ссылке).

## Изменения в `+page.svelte`

- Split-кнопка вместо текущей кнопки «Сгенерировать»
- `let fridgeModalOpen = $state(false)`
- `fridgeItems = $derived(page.data.fridgeItems as FridgeRow[])` — уже грузится в layout
- `handleFridgeGenerate(selected: FridgeRow[])`:
  1. Закрыть `FridgeSelectModal`
  2. Вызвать `buildFridgeHints(selected, allDishes)` → hints
  3. Вызвать `generateWeekPlan({ ...opts, fridgeHints: hints })`
  4. Сохранить результат в Supabase (существующая логика `handleGenerate`)

## Что не меняется

- Таблицы Supabase — без изменений
- RLS — без изменений
- Обычная генерация (основная кнопка) — без изменений
- Диалог подтверждения «Заменить меню?» — остаётся для обычной генерации; для fridge-генерации подтверждение встроено в кнопку диалога

## Граничные случаи

| Ситуация | Поведение |
|---|---|
| Холодильник пуст | Пункт «С учётом холодильника…» недоступен |
| Продукт не найден ни в одном блюде | Тихо игнорируется |
| Бюджет > 7 (запас на всю неделю) | `slotsLeft = Math.min(budget, 7)` |
| Единица измерения не граммовая | Фолбэк порции 150г |
| Все чекбоксы сняты | Кнопка «Сгенерировать» неактивна |
