**Приоритет:** 🟡 высокий  
**Статус:** 📋 не начато  
**Дата:** 2026-04-08

---

## Описание

Как пользователь, я хочу нажать на блюдо в сетке недели и увидеть его детальную карточку —
фото, название, КБЖУ и список ингредиентов — чтобы освежить в памяти что входит в блюдо
и понять из чего состоит его питательная ценность.

---

## Поведение

- Клик по MealCard открывает `DishDetailModal`
- Крест или клик по фону — закрывает
- `Escape` — закрывает
- Кнопка «Удалить из плана» — вызывает `onremove`, закрывает модалку

## Данные

### Добавить в SeedDish
```typescript
ingredients?: string[];  // список ингредиентов, опционально
```

Примеры:
```typescript
{ name: 'Тушёная говядина с овощами', ingredients: ['говядина 120г', 'морковь 30г', 'лук 20г', 'томатная паста 15г', 'специи'] }
{ name: 'Гречка отварная', ingredients: ['гречневая крупа', 'соль'] }
```

Если `ingredients` не задан — блок «Ингредиенты» не отображается.

### Данные из MenuPlanRow (уже есть)
- `dish_name`, `dish_photo`, `kcal`, `protein`, `fat`, `carbs`, `grams`, `cost`

> ⚠️ Ингредиенты берём из `SeedDish` по имени (`dish_name`).
> При интеграции FatSecret — из их API.

## Компонент DishDetailModal

```typescript
interface Props {
  plan:      MenuPlanRow;
  dish?:     SeedDish | null;  // для ингредиентов, опционально
  onclose:   () => void;
  onremove:  () => void;
  onreplace: () => void;       // закрывает карточку, открывает MealModal для замены
}
```

---

## Изменения в MealCard

MealCard получает новый prop `onclick?: () => void`.
При клике на карточку (не на кнопку удаления) вызывается `onclick`.

В +page.svelte при клике открывается `DishDetailModal` с нужным `plan` и `dish`.
