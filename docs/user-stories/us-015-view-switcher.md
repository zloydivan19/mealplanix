## Описание

Как пользователь, я хочу переключаться между видом недели и видом дня
одним нажатием, чтобы быстро менять уровень детализации планировщика.

---

## UI

Сегмент-переключатель в строке навигации по неделям:

```
[←]   6 апр – 12 апр   [Неделя | День]   [→]
       Текущая неделя
```

- Таблетка с двумя вариантами: **Неделя** / **День**
- Активный вариант — зелёный фон (`var(--color-green-primary)`), белый текст
- Неактивный — прозрачный фон, серый текст
- При переходе в Day View стрелки `←` / `→` переключают дни, не недели

---

## Поведение стрелок в зависимости от режима

| Режим   | ← / → |
|---------|-------|
| Неделя  | предыдущая / следующая неделя |
| День    | предыдущий / следующий день |

---

## Стейт

```typescript
type ViewMode = 'week' | 'day';
let viewMode  = $state<ViewMode>('week');
let dayOffset = $state(0);  // смещение дня от сегодня (0 = сегодня)
```

- `weekOffset` остаётся для Week View
- `dayOffset` используется только в Day View
- При переключении Week → Day: `dayOffset` = сегодня (0)
- При переключении Day → Week: возвращаемся в ту же неделю
