# US-022 — WeekGrid: переработка — день строкой, приёмы столбцами

**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу видеть меню сгруппированным по дням,
а внутри каждого дня — все приёмы пищи рядом в одну строку,
чтобы воспринимать день как единое целое, а не искать его по столбцам недели.

## Проблема (было)
CSS Grid 7 колонок (дни) × 3 строки (приёмы) — горизонтальный скролл на мобильном,
трудно читать один день целиком.

## Решение (стало)
Вертикальный список из 7 карточек-дней. Внутри каждой карточки — 4 колонки:
Завтрак / Обед / Ужин / Перекус.

## Макет (десктоп)

```
┌──────────────────────────────────────────────────────────────┐
│  Понедельник, 7 апр    [Сегодня]              ~1980 ккал     │
├───────────────┬───────────────┬───────────────┬──────────────┤
│  ЗАВТРАК      │  ОБЕД         │  УЖИН         │  ПЕРЕКУС     │
│  [MealCard]   │  [MealCard]   │  [+ добавить] │  [MealCard]  │
│  + добавить   │  + добавить   │               │  + добавить  │
├───────────────┴───────────────┴───────────────┴──────────────┤
│  Вторник, 8 апр                               ~2100 ккал     │
│  ...                                                         │
└──────────────────────────────────────────────────────────────┘
```

## Детали карточки дня

- **Заголовок:** `DAY_FULL, дата` + бейдж "Сегодня" (если текущий день)
- **Итог ккал дня** — сумма ккал по всем слотам, показывается если > 0
- **Зелёная левая полоса** (4px) + зелёный фон заголовка для текущего дня
- **4 колонки** через CSS Grid `repeat(4, 1fr)`, разделены линией `var(--color-border)`
- **Лейбл приёма** — uppercase, 11px, + итог ккал слота справа

## Новый приём: Перекус (sn)

- Добавлен 4-й `MealKey`: `'sn'`
- `MEAL_LABELS` дополнен: `sn: 'Перекус'`
- В `generate.ts` — перекус генерируется как ~10% от `kcal_target`
- 7 seed-блюд категории `sn` добавлены в `seed-dishes.ts`
- CHECK constraint в Supabase обновлён: `meal_key IN ('bf','ln','dn','sn')`

## Мобильный адаптив
- `> 768px`: 4 колонки в строке
- `< 768px`: колонки схлопываются в стопку (каждый приём под другим)
