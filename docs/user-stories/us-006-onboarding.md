# US-006 — Онбординг: создание первой персоны

**Эпик:** Семья и персоны  
**Приоритет:** 🔴 критично  
**Статус:** ✔️ готово  
**Дата:** 2026-04-07

## Описание
Как новый пользователь, я хочу создать свой профиль питания сразу после регистрации,
чтобы сервис мог рассчитать мою норму КБЖУ и я мог начать планировать меню.

## Сценарий
1. Регистрируюсь → меня перебрасывает на `/onboarding`
2. **Шаг 1:** Вижу приветствие и кнопку "Начать"
3. **Шаг 2:** Заполняю имя, пол, возраст, вес, рост, уровень активности
   - КБЖУ рассчитывается автоматически при изменении любого поля (Mifflin-St Jeor / Harris-Benedict)
   - Могу вручную скорректировать калории (с кнопкой "Сброс")
   - Задаю распределение по приёмам пищи: Завтрак / Обед / Ужин (сумма = 100%)
4. **Шаг 3:** Вижу код приглашения семьи, нажимаю "Перейти к меню" → `/`

## Definition of Done
- [x] 3-шаговый wizard с индикатором прогресса
- [x] Автоматический расчёт КБЖУ через `$derived.by()` при изменении полей
- [x] Ручная коррекция kcal с кнопкой сброса
- [x] Валидация суммы meal_ratios (bf + ln + dn === 100)
- [x] Сохранение персоны в таблицу `personas` с полями: gender, age, weight, height, activity, formula, kcal_target, protein_target, fat_target, carbs_target, meal_ratios
- [x] На шаге 3 показывается invite_code домохозяйства
- [x] Если персона уже есть — `/onboarding` недоступен (редирект на `/`)
