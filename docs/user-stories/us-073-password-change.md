# US-073 — Смена пароля

**Дата:** 2026-04-14
**Статус:** утверждено
**Эпик:** Эпик 7 — Настройки
**Задачи:** V5-073

---

## Цель

Авторизованный пользователь может сменить пароль прямо в настройках. Неавторизованный — восстановить пароль через email.

---

## User Stories

### US-073-A — Смена пароля в настройках
**Как** авторизованный пользователь  
**Я хочу** сменить пароль в разделе настроек  
**Чтобы** обновить пароль без выхода из аккаунта

**Acceptance criteria:**
- В `/settings` секция «Безопасность» с кнопкой «Сменить пароль»
- Форма: «Новый пароль» + «Повтор пароля» (минимум 6 символов)
- При сохранении вызов `supabase.auth.updateUser({ password })`
- Успех — toast «Пароль обновлён», форма сбрасывается
- Ошибка — показывается сообщение под полем

### US-073-B — Восстановление пароля (forgot password)
**Как** пользователь, который забыл пароль  
**Я хочу** получить ссылку для сброса пароля на email  
**Чтобы** восстановить доступ к аккаунту

**Acceptance criteria:**
- На странице `/auth` ссылка «Забыли пароль?»
- Открывается форма с полем email + кнопка «Отправить ссылку»
- Вызов `supabase.auth.resetPasswordForEmail(email, { redirectTo })`
- После отправки: сообщение «Ссылка отправлена на {email}» (независимо от того, существует ли email — защита от enumeration)
- Переход по ссылке из письма → Supabase редиректит на `/auth/reset` с токеном в URL
- Страница `/auth/reset` — форма «Новый пароль» + «Повтор», вызов `supabase.auth.updateUser({ password })`
- После успеха — редирект на `/`
