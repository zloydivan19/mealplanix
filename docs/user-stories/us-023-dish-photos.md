**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу видеть фото блюда в карточке,
чтобы быстро визуально ориентироваться в меню не читая название.

## Макет карточки с фото

```
┌────────────────────────────────────┐
│ [фото]  Сырники со сгущёнкой    ✕  │
│  48×48  230 ккал · Б11 Ж9 У25      │
│         ~90 ₽                      │
└────────────────────────────────────┘
```

- Фото слева: квадрат 48×48px, `border-radius: 8px`, `object-fit: cover`
- Если фото нет — зелёный placeholder с иконкой тарелки
- Фото хранятся в `static/dishes/`, путь в поле `SeedDish.photo`

## Источники фото (временные, до FatSecret)

Фото из `photodishes/` копируются в `static/dishes/` и привязываются
к конкретным блюдам в `seed-dishes.ts` через поле `photo?: string`.
Блюда без фото отображают placeholder.
