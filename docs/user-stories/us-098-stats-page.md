# US-098: Страница /stats — недельный КБЖУ-график

**Статус:** ✔️ готово
**Эпик:** Phase 3 — Premium Value
**Дата:** 2026-05-12

---

## User Story

> Как пользователь, я хочу видеть на странице `/stats` график своего недельного КБЖУ по дням против цели персоны, чтобы понимать насколько реальное меню соответствует моим питательным целям.

---

## Acceptance Criteria

1. Новый роут `/stats` (пункт «Статистика» в сайдбаре между Холодильником и Настройками).
2. Шапка: переключатель недель + персона-чипы (если в семье >1 персоны).
3. **3 сводные карточки сверху:**
   - **Adherence Score** — 0–100% насколько неделя близка к целям (по всем метрикам × всем дням, среднее отклонение)
   - **Среднее в день** — текущее среднее ± % отклонения от цели
   - **Цель** — целевое значение из персоны
4. **Переключатель метрики:** Калории / Белки / Жиры / Углеводы (segmented tabs).
5. **График:** ApexCharts bar chart, 7 столбцов (Пн–Вс):
   - Цвет столбцов: зелёный ±5% от цели, жёлтый ±15%, красный >15%
   - Пунктирная линия цели с подписью «Цель: X ккал»
   - Анимации входа, tooltip с точным значением
6. **Empty states:**
   - Нет персоны → CTA «Открыть настройки»
   - Меню пустое → CTA «К планировщику»
7. Тёмная тема — график перерисовывается при смене темы.

## Технические детали

### Библиотеки
- `apexcharts` (~150 kb gzip)
- SSR отключён: `+page.ts` → `export const ssr = false`

### Расчёт adherence score
Для каждого непустого дня × каждой метрики (kcal/protein/fat/carbs):
```
dev = |value - target| / target
score = max(0, 1 - dev)
```
Adherence = среднее всех scores × 100.

### Цветовая маркировка столбцов
- `±5%` → основной цвет метрики
- `±15%` → amber `#f59e0b`
- `>15%` → red `#ef4444`
