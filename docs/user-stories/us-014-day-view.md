**Эпик:** Меню  
**Приоритет:** 🟡 высокий  
**Статус:** 📋 не начато  
**Дата:** 2026-04-08

---

## Описание

Как пользователь, я хочу смотреть план на конкретный день в развёрнутом виде —
с полными карточками блюд, фото и итоговой КБЖУ за день — чтобы удобно планировать
и контролировать питание без скролла по всей неделе.

## Поведение

- Навигация между днями: `←` / `→` кнопки в заголовке
- Переход через неделю (если сегодня воскресенье → следующий понедельник)
- Клик на блюдо → `DishDetailModal` (US-028) — с заменой/удалением
- `+ добавить блюдо` → `MealModal` (US-026)
- Иконки приёмов: 🌅 завтрак, 🍽 обед, 🌙 ужин, 🍎 перекус
- Блок «Итого за день»:
  - Прогресс-бар ккал (факт / цель)
  - Цветные Б/Ж/У (US-027)
  - Показывается только если `match_kcal = true` и есть `kcal_target`
  - Подсказка недобора если < 90% нормы

---

## Начальный день при открытии Day View

- При переключении с Week View → открывается текущий день (сегодня)
- Если переключили на конкретный день из Week View — открывается тот день (опционально, v2)
