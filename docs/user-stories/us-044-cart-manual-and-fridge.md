# US-044 — Корзина: ручные позиции + перенос в холодильник

**Дата:** 2026-04-14
**Статус:** утверждено
**Эпик:** Эпик 4 — Корзина
**Задачи:** V5-044, V5-053

---

## Цель

Пользователь может добавить в корзину произвольные позиции (не из меню) и после похода в магазин одним действием перенести всё купленное в холодильник.

---

## User Stories

### US-044-A — Ручное добавление позиции в корзину
**Как** пользователь  
**Я хочу** добавить в корзину продукт вручную  
**Чтобы** использовать корзину как единый список покупок, включая то, что не связано с меню

**Acceptance criteria:**
- В конце страницы `/cart` есть строка «+ Добавить вручную» (не модалка — инлайн-форма)
- Поля: название (text, required), количество (number), единица (г / мл / шт / упак), категория (select, default «Прочее»)
- После сохранения позиция появляется в соответствующей категорийной группе с меткой «вручную»
- Ручные позиции синхронизируются в `cart_state` с флагом `source = 'manual'`
- Ручную позицию можно удалить; позиции из меню — нельзя (удаление через меню)
- Если пользователь не авторизован — кнопка задизейблена

### US-044-B — Перенос купленного в холодильник
**Как** пользователь, который вернулся из магазина  
**Я хочу** перенести все отмеченные позиции из корзины в холодильник одним нажатием  
**Чтобы** холодильник автоматически отражал то, что я купил, без ручного ввода

**Acceptance criteria:**
- В шапке `/cart` кнопка «В холодильник» — активна только когда есть хотя бы одна отмеченная позиция (`is_checked = true`)
- При нажатии: все `is_checked` позиции с `qty` и `unit` передаются в `household_fridge` (upsert по `product_name + household_id`, qty суммируется)
- После успешного переноса: toast «Добавлено X позиций в холодильник» со ссылкой «Открыть /fridge»
- Отмеченные позиции остаются отмеченными в корзине — не удаляются
- Если `householdId` не определён — кнопка скрыта

## Схема БД

Новое поле в `cart_state` (JSONB или отдельная колонка):
```sql
-- Добавить поле source в существующую cart_state структуру:
-- source: 'menu' | 'manual'  (default 'menu')
```

Используется существующая таблица `household_fridge` без изменений схемы.
