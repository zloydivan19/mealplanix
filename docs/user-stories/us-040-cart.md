## Описание

Как пользователь, я хочу видеть сводный список ингредиентов из меню на неделю,
чтобы взять телефон и пойти в магазин не думая что купить.

---

## Источник данных

- Берём все `menu_plans` текущего домохозяйства за выбранную неделю (все персоны)
- Для каждого блюда ищем его в `SEED_DISHES` по `dish_name`
- Извлекаем `ingredients: Ingredient[]` — объекты `{ name, category }`
- Ингредиенты с одинаковым `name` (trim + lowercase) объединяются в одну строку
- Если блюдо не найдено в seed — само блюдо добавляется как ингредиент категории `other`

## Структура данных

```typescript
export type ShoppingCategory = 'meat' | 'dairy' | 'grain' | 'vegetable' | 'fruit' | 'condiment' | 'other';
export interface Ingredient { name: string; category: ShoppingCategory; }
```

Поле `ingredients?: Ingredient[]` заменяет старый `ingredients?: string[]` в SeedDish.

## Поведение

- Клик на строку → отмечает купленным (зачёркивание + серый)
- Купленные опускаются в конец своей категории
- Счётчик «Куплено X / Y» в шапке
- Состояние чекбоксов → `localStorage` (`pm_cart_checked_{weekId}`)
- Навигация `←` / `→` по неделям, weekId в `pm_cart_week`
- Пустой стейт: «Сгенерируйте меню на эту неделю»
