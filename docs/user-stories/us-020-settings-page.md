# US-020 — Страница настроек: профиль + генерация меню

**Эпик:** Настройки  
**Приоритет:** 🔴 критично  
**Статус:** ✔️ готово  
**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу редактировать свой профиль и настройки генерации меню
в одном месте, чтобы при изменении данных (вес, активность, цель по калориям)
меню пересчитывалось корректно.

## Сценарий

1. Перехожу в Настройки через боковое меню или ссылку в шапке
2. Вижу кнопку "← Назад" → возвращает на главную
3. Вижу два раздела: **Профиль** и **Генерация меню**
4. Редактирую нужные поля
5. Нажимаю "Сохранить" → данные обновляются в Supabase
6. Вижу подтверждение "Сохранили ✓"

## Раздел "Профиль"

Поля для редактирования:
- **Имя** — текстовое поле
- **Пол** — переключатель Мужской / Женский
- **Возраст** — число
- **Вес (кг)** — число
- **Рост (см)** — число
- **Уровень активности** — выпадающий список (5 значений)

## Раздел "Генерация меню"

### Тумблер "Считаю калории и слежу за КБЖУ" (`match_kcal`)

**Включён:**
- Разворачивается блок расчёта суточной нормы КБЖУ (из профиля)
- Возможность ручной коррекции калорий
- Поля распределения по приёмам пищи (Завтрак / Обед / Ужин, сумма = 100%)
- Блюда при генерации подбираются ближайшие по ккал к норме

**Выключен:**
- Блок КБЖУ скрыт
- Блюда при генерации выбираются случайно
- Текст: "Блюда выбираются случайно — удобно, если считать ккал не хочется"

### Тумблер "Переносить ужин на обед следующего дня" (`carry_dinner_to_lunch`)

- По умолчанию включён
- При генерации меню обед каждого дня = ужин предыдущего

## Валидация

- Имя: обязательно
- Если `match_kcal=true`: возраст + вес + рост обязательны
- Если `match_kcal=true`: сумма % по приёмам должна быть 100
