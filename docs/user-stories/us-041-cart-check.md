# US-041 — Корзина: ручное добавление и управление списком

**Эпик:** Корзина  
**Приоритет:** 🟢 средний  
**Статус:** 📋 не начато  
**Дата:** 2026-04-08

---

## Описание

Как пользователь, я хочу добавлять в корзину позиции вручную и удалять ненужные,
чтобы список точно отражал что мне нужно купить.

---

## Поведение

- Кнопка «+ Добавить» в конце каждой категории → инлайн-инпут с названием
- Кнопка «× Удалить» при наведении на строку (только для ручных позиций)
- Автогенерированные позиции нельзя удалить (только отметить купленным)
- Кнопка «Очистить купленное» — убирает все отмеченные позиции
- Кнопка «Сбросить» — возвращает к исходному списку из меню

---

## Definition of Done

- [ ] Инлайн-добавление позиции в категорию
- [ ] Удаление ручных позиций
- [ ] «Очистить купленное»
- [ ] «Сбросить список»
- [ ] Ручные позиции сохраняются в localStorage
