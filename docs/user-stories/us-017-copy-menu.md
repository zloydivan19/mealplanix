# US-017 — Копирование меню

**Дата:** 2026-04-14
**Статус:** утверждено
**Эпик:** Эпик 2 — Меню
**Задачи:** V5-017

---

## Цель

Пользователь может скопировать меню целой недели или одного дня на другую неделю/день, чтобы не вводить одни и те же блюда каждый раз вручную.

---

## User Stories

### US-017-A — Копирование недели
**Как** пользователь с повторяющимся рационом  
**Я хочу** скопировать меню текущей недели на другую неделю  
**Чтобы** не заполнять одни и те же блюда каждые 7 дней

**Acceptance criteria:**
- В навигации недели (рядом с ← →) кнопка-иконка «Копировать неделю»
- Открывается попап: «Скопировать неделю [X] на» + выбор недели (следующая / ввод вручную)
- Если целевая неделя не пустая — предупреждение «Неделя [Y] уже содержит блюда. Перезаписать?»
- При подтверждении: клонируются все записи `menu_plans` текущей недели с новым `week_label` и `persona_id` текущей активной персоны
- После копирования: автопереход на целевую неделю + toast «Меню скопировано»
- Кнопка показывает spinner во время операции

### US-017-B — Копирование дня
**Как** пользователь  
**Я хочу** скопировать меню конкретного дня в другой день  
**Чтобы** быстро повторить удачный день без пересоздания

**Acceptance criteria:**
- В day-view в шапке дня кнопка «Скопировать день»
- Попап: выбор целевого дня (день недели + выбор недели: текущая / следующая)
- Если целевой день не пустой — предупреждение «День [Y] уже заполнен. Перезаписать?»
- При подтверждении: клонируются все `menu_plans` за выбранный `day_index` с новыми `day_index` и `week_label`
- Toast с undo-кнопкой «Отменить» (5 секунд) — при нажатии удаляет скопированные записи

### US-017-C — Undo последнего копирования
**Как** пользователь, который случайно скопировал не туда  
**Я хочу** отменить последнее копирование  
**Чтобы** не очищать неделю вручную

**Acceptance criteria:**
- После любого копирования (неделя или день) показывается toast с кнопкой «Отменить» (таймаут 5 сек)
- Нажатие на «Отменить» удаляет только что скопированные записи (хранить список ID в памяти)
- После закрытия toast или истечения таймаута undo недоступен
