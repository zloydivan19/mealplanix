**Эпик:** Настройки / Блюда  
**Приоритет:** 🟡 высокий

---

## Описание

Как пользователь, я хочу добавлять свои блюда вручную — с КБЖУ, ценой и ингредиентами — чтобы они появлялись в планировщике рядом с готовыми блюдами.

---

## Макет — страница /dishes

```
Мои блюда                              [+ Добавить блюдо]

┌─────────────────────────────────────────────────────┐
│ 🍳 Омлет с овощами          завтрак                 │
│ 145 ккал/100г · Б12 · Ж9 · У4 · ~35 ₽/100г        │
│ Ингредиенты: яйца, перец, помидоры, масло           │
│                                        [✏] [🗑]    │
└─────────────────────────────────────────────────────┘
...
```

Пустой стейт: «У вас пока нет своих блюд. Добавьте первое!»

---

## Форма создания / редактирования (модалка)

**Обязательные поля:**
- Название
- Категория: Завтрак / Основное / Гарнир / Салат / Перекус
- Ккал на 100г
- Белки на 100г
- Жиры на 100г
- Углеводы на 100г
- Порция по умолчанию (г)

**Необязательные:**
- Стоимость на 100г (₽)
- Ингредиенты (теги через запятую или Enter)

---

## Хранение

Таблица `custom_dishes` (уже есть в схеме):
```
household_id  uuid
data          jsonb  ← CustomDishData
```

Структура `data`:
```typescript
interface CustomDishData {
  name:              string;
  category:          DishCategory;        // 'breakfast' | 'main' | 'side' | 'salad' | 'snack'
  kcal_per_100g:     number;
  protein_per_100g:  number;
  fat_per_100g:      number;
  carbs_per_100g:    number;
  portion_default_g: number;
  cost_per_100g:     number;
  ingredients:       Ingredient[];        // { name, category }
  source:            'custom';
}
```

---

## Интеграция с планировщиком

- В `MealModal` кастомные блюда отображаются рядом с seed-блюдами
- Визуально помечены бейджем «Моё»
- Можно добавить в план как обычное блюдо
