## Описание

Как пользователь, я хочу видеть Белки / Жиры / Углеводы каждый своим цветом,
чтобы мгновенно считывать баланс макронутриентов без чтения подписей.

---

## Цветовая схема

| Макронутриент | Цвет        | Hex       |
|---------------|-------------|-----------|
| Б (белки)     | синий       | `#1D4ED8` |
| Ж (жиры)      | оранжевый   | `#FF8F00` |
| У (углеводы)  | жёлтый      | `#D97706` |

Цвета уже используются в блоке «Твоя суточная норма» в настройках — оставляем те же.

---

## Где применяется

1. **MealCard** (карточка блюда на неделе)
   ```
   218 ккал · Б27 · Ж11 · У6
   ```
   Каждое значение своим цветом.

2. **MealModal шаг 2** (превью при вводе граммовки)
   ```
   218 ккал
   Б27 · Ж11 · У6
   ```

3. **MealModal шаг 1** (список блюд) — добавить БЖУ/100г под названием
   ```
   Тушёная говядина
   145 ккал/100г  Б18 · Ж7 · У3
   ```
