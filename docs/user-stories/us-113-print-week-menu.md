# US-113 — Печать меню на неделю (A4)

**Статус:** ✔️ готово
**Дата:** 2026-07-28

## Задача

Как пользователь, я хочу распечатать меню на неделю в аккуратном виде на листе A4, чтобы повесить его на холодильник и видеть план питания без телефона/ноутбука.

## Реализация

- Кнопка «🖨 Печать» в шапке WeekGrid (рядом с переключателем Неделя/День) открывает режим предпросмотра — новый компонент `src/lib/components/PrintMenu.svelte`, без отдельного route.
- Печатается меню активной персоны за текущую выбранную неделю.
- Макет: брендовая шапка (логотип + «MealPlaniX»), «Меню на неделю», период + имя персоны, 2 колонки дней (Пн–Ср / Чт–Сб), воскресенье — по центру снизу. Несколько блюд в одном приёме — через запятую. Итог КБЖУ за день — одной строкой под приёмами пищи. Пустой день — «День не запланирован».
- Печать — нативный `window.print()`, без PDF-библиотек. `@media print` скрывает сайдбар и служебные кнопки, форсирует светлую тему независимо от темы приложения, `@page { size: A4; margin: 12mm }`.
- Данные для печати берутся из уже загруженного реактивного состояния меню (`localPlans`), без дополнительных запросов к серверу.

## Баги, найденные и исправленные при ручном тестировании

- Правила скрытия сайдбара/сброса отступа при печати не срабатывали из-за более высокой специфичности scoped-стилей Svelte — добавлен `!important` точечно на два правила.
- Печать использовала устаревший снимок меню (`data.menuPlans` с сервера) вместо реактивного `localPlans` — после правки меню без перезагрузки страницы печатался старый список. Исправлено переключением источника данных на `localPlans`.
- Шрифты изначально были слишком мелкими для чтения с холодильника — увеличены; после этого неделя с насыщенным меню перестала помещаться на один лист — размеры подобраны заново под компромисс читаемость/один лист A4.
- Шапка логотип+wordmark была визуально несимметрична — добавлен уравновешивающий invisible-spacer справа от текста.

## Вне области

- Печать меню нескольких персон одновременно.
- Генерация PDF-файла.
- КБЖУ по каждому блюду на распечатке (только итог за день).
