## Описание

Как пользователь, я хочу искать продукты/блюда по названию через FatSecret
и получать КБЖУ автоматически, чтобы не вводить цифры вручную при создании
кастомного блюда.

---

## Архитектура

```
Браузер → POST /api/fatsecret?q=курица → SvelteKit server route
                                          ↓
                                   FatSecret OAuth2 (client_credentials)
                                          ↓
                                   foods.search.v3 (JSON)
                                          ↓
                                   Нормализованный список → браузер
```

### Почему серверный роут
- Ключи `client_id` / `client_secret` не должны попасть в браузер
- Токен кэшируется в памяти сервера (живёт 24ч)

---

## Серверный роут

`src/routes/api/fatsecret/+server.ts`

```typescript
GET /api/fatsecret?q=курица&max=10
```

Ответ:
```json
[
  {
    "id": "1234",
    "name": "Куриное филе варёное",
    "kcal": 110,
    "protein": 23.6,
    "fat": 1.2,
    "carbs": 0,
    "per": "100g"
  }
]
```

---

## Интеграция в /dishes

- Поле поиска в форме создания блюда
- По мере ввода (debounce 400ms) → запрос к `/api/fatsecret`
- Список результатов → клик → автозаполнение КБЖУ полей
- Пользователь может скорректировать и сохранить
