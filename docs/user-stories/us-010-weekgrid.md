# US-010 — WeekGrid: сетка меню на неделю

**Эпик:** Меню  
**Приоритет:** 🔴 критично  
**Статус:** ✔️ готово  
**Дата:** 2026-04-08

## Описание
Как пользователь, я хочу видеть сетку меню на текущую неделю (7 дней × 3 приёма пищи),
чтобы видеть план питания целиком и быстро понимать, что и когда запланировано.

## Сценарий
1. Вхожу в приложение → вижу главный экран
2. Вверху — ряд персон домохозяйства, активная выделена зелёной рамкой
3. Могу переключиться на другую персону кликом
4. Под персонами — навигация по неделям: `← | 14 апр – 20 апр | →`
5. Ниже — сетка: колонки = дни (Пн–Вс с числом), строки = Завтрак / Обед / Ужин
6. Текущий день визуально выделен (зелёный фон заголовка и слотов)
7. Пустые слоты — пунктирная рамка с текстом "+ блюдо", при hover зеленеют
8. Нажимаю ← / → — неделя меняется, метка обновляется
