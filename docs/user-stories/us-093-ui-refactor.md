# US-093 — UI-рефакторинг: SVG-иконки, выравнивание шапок, улучшения планировщика

**Дата:** 2026-04-14
**Статус:** ✔️ готово
**Эпик:** Эпик 1 — Инфраструктура и фундамент

---

## Описание
Как пользователь, я хочу видеть единообразный интерфейс без эмодзи и визуальных несоответствий,
чтобы приложение выглядело профессионально и согласованно.

## Что сделано

### Выравнивание шапок (все страницы)
- Шапка сайдбара: `110px → 56px`
- Все страницы (fridge, dishes, settings, cart) приведены к единой высоте `56px`
- Убраны лишние `padding-top/bottom` из заголовков, заменены на `height: 56px; align-items: center`
- Типографика заголовков: `font-bold text-lg → font-semibold 15px letter-spacing: -0.01em`

### Планировщик (`+page.svelte`)
- SVG-иконки приёмов пищи вместо эмодзи (завтрак/обед/ужин/перекус)
- Акцентная полоска слева у заголовков приёмов (3px colored border-left)
- Прогресс-бар калорий в week view (зелёный / жёлтый / красный)
- Кнопка «+ добавить блюдо» → dashed border + SVG плюс
- Иконка тарелки вместо `🍽` в пустом слоте
- SVG крестик вместо `✕` при удалении
- SVG чекмарк вместо `✓` в сообщениях прогресса
- SVG треугольник предупреждения вместо `⚠`
- `cursor-pointer` на кнопках week view

### Страница /fridge
- Пустое состояние: SVG-иконка холодильника вместо `🧊`
- Иконка в строке продукта: SVG вместо `🧊`
- Предупреждения о сроке: SVG треугольник вместо `⚠`

### Страница /dishes
- Иконки категорий блюд: SVG-пути вместо эмодзи-строк во всех трёх местах рендера

### Страница /settings
- Sticky 56px topbar: кнопка назад (SVG `←`) + заголовок
- `Сохранили ✓` → SVG чекмарк + «Сохранено»
- Сумма БЖУ-соотношений: `✓` → SVG чекмарк

### Страница /onboarding
- Индикаторы шагов: `✓` текст → SVG чекмарк
- Переключатель: исправлен баг дублирующегося атрибута `style`
- `🎉` → SVG круг с чекмарком
- Кнопки навигации: `←`/`→` → SVG-стрелки

### Страница /auth
- Табы: добавлены `cursor-pointer` + hover-эффекты на неактивных табах
- Кнопки: спиннер при загрузке + `flex items-center justify-center gap-2`
